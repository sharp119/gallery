top of it. Reuse Gallery capabilities (on-device LLM/LiteRT, Audio Scribe,
Mobile Actions, Agent Skills, MCP); add the Tiffin layer (daemon, shake trigger,
proactive loop, notifications). Keep the upstream `LICENSE` and attribution intact;
the original Gallery README lives at `docs/upstream/AI_EDGE_GALLERY_README.md`.
