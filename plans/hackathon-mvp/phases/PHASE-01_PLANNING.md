# Phase 1 — Plan Tiffin

## Goal

After the base app runs (Phase 0), decide exactly what Tiffin adds and break it
into detailed phases.

## Tasks

- [ ] List the Tiffin features we want (start: daemon, shake trigger, proactive
      loop, notifications; later: laptop pairing, more triggers).
- [ ] For each feature, decide: reuse a Gallery capability, or add new code?
- [ ] Explore the Gallery `Android/` app and find the hook points (where to add a
      background service, how to call Audio Scribe + the on-device LLM).
- [ ] Write a detailed phase doc per chunk of work under
      `plans/hackathon-mvp/phases/`.
- [ ] Update `HANDOFF.md` and `DECISION_LOG.md`.

## Close Criteria

- A written, agreed phase plan for the Tiffin layer exists.
