# Phase 0 — Build & Run The Original App

## Goal

Get the **unmodified** Google AI Edge Gallery app building and running on a real
Android device. This is the baseline; no Tiffin code is added in this phase.

## Tasks

- [ ] Read upstream `DEVELOPMENT.md`.

- [ ] Install + run on a physical device (USB debugging on).
- [ ] Download and run a model from the list (LiteRT).
- [ ] Try Audio Scribe (voice) and Mobile Actions.
- [ ] Write down the exact toolchain versions that worked, and any fixes needed.

## Close Criteria

- The stock Gallery app runs on-device.
- A model runs locally; Audio Scribe and Mobile Actions work.
- The working build steps are recorded here.
